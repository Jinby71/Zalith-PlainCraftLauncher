# 1.5.0

**versionCode** `200072` · **包名** `com.zalith.pcl` · **minSdk** 26 · **targetSdk** 34

---

这是 **Zalith-Plain Craft Launcher** 的 1.4.6 版本。

- 版本号：1.4.6

### 新增

- **导入入口拆分**：文件管理器「打开方式」里新增「导入模组」「导入布局」两个独立入口，与「导入整合包」并列；原来的通配入口保留兜底。
- **插件页手动安装入口**：新增「从文件选择 APK」，走系统文件选择器，不依赖任何存储权限，国产 ROM 也能装插件。

### 优化

- **外观全部交还主题**：按钮、滑条、圆角、弹窗阴影与圆角，全部改由皮肤插件的 `ui.json` 决定，启动器不再替主题做决定。没装主题时保持 PCL 原样。
- **软玻璃真实模糊**：低版本与弹窗的玻璃改用真实高斯卷积，消费插件的 `glass.blur`；新增 `glass.quality`（low/normal/high）清晰度档位。
- **插件页诊断显示主题名**：一眼看出当前生效的是哪个主题、什么渲染器。

### 修复

- **弹窗马赛克**：软玻璃底片改用「按工作分辨率绘制 + 双阶段缩放」，消除大块玻璃的方块与采样接缝。
- **顶栏下方深色横线**：软玻璃不再给面板画厚度边，顶栏与内容区连成一片。
- **按钮残留玻璃边**：装了主题就走主题表面，不再退回 PCL 白底描边按钮。

### 升级

包名不变（`com.zalith.pcl`），可直接覆盖安装 1.4.0 / 1.3.x。


### 更新

- 基岩版下载页使用原版列表样式，并由插件按版本提供下载源。


### 优化

- 插件入口可直接显示在版块主栏，首页插件面板支持居中主体和底部操作区。


### 优化

- 基岩版版本下载源使用原生列表选择样式，网盘与提取码统一显示在选项中。

### Update

- **Plugin entries in setup**: plugins can add their own entry to the settings list; the launcher only provides the interface, the page itself comes from the plugin.

### Fix

- **Plugin upgrade re-extract**: installing a newer plugin APK now re-extracts its `pages.json` and assets instead of keeping the old ones.

### 修复

- **弹窗按钮显示不全**：面板限高到可用高度，正文区自己滚动，按钮行固定在底部；低缩放或矮窗口下不再被裁掉。

### 修复

- **整合包导出崩溃**：文件夹名里带 `[` `]`（如 `[宝]`）时，导出规则被当成非法正则直接抛 `PatternSyntaxException`；现在做了转义与兜底，最坏也只是那条规则不匹配。

### 修复

- **整合包导入报 ENOENT**：下载好的包与旧任务共用同一个文件名，旧任务晚到的清理把它删掉了；现在每次尝试独立命名，并且在交给导入器前先确认文件还在。

### 修复

- **前置资源返回跳回主页**：二级页原来是单槽位覆盖，资源详情里点前置会把上一层顶掉；改成真正的页面栈，返回逐层回退。

### 新增

- **官网下载入口**：更新弹窗里常驻一行「从官网下载（若下载缓慢）」，点了直接开官网；GitHub 直连慢时不用再等。

### 变更

- **模组 / 整合包默认源改为 Modrinth**：下载版块「模组」「整合包」的来源下拉默认选中 Modrinth，设置里的初始搜索平台默认值同步调整；CurseForge 仍可手动切换。

### 修复

- **鼠标划过时高亮串行闪烁**：列表项 / 菜单行 / 下拉选项 / 卡片阴影的指向高亮原来「离开」也要淡出 120–300ms，鼠标一快就会出现前几行没退、后几行已亮的拖尾；现在改为进入 60ms、离开立即生效。

### 调整

- **默认下载线程数 16 → 32**：新装即 32 条并发连接；老用户若还停在旧默认 16 会自动抬到 32，手动调过的值不动。设置 → 下载 → 最大线程数仍可随时改。

### 版本

- 对外版本号统一为 **1.5.0**（内部 versionCode 200072，仍严格递增，可直接覆盖安装）。
